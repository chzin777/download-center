## Sobre o Projeto

Este site foi desenvolvido para centralizar os principais downloads de programas, utilitários, drivers e links importantes utilizados no dia a dia da **R3 Suprimentos**.  
O objetivo é facilitar o acesso dos colaboradores às ferramentas essenciais para o trabalho, organizando todos os arquivos e links em um só lugar.

---

## Funcionalidades

- **Downloads organizados:** Drivers de impressoras, softwares essenciais e utilitários.
- **Links importantes:** Acesso rápido a sistemas internos, ativadores e plataformas corporativas.
- **Design moderno:** Visual limpo e interface intuitiva.

---

## Como usar

1. Clone ou baixe este repositório.
2. Hospede o arquivo `index.html` em um servidor interno ou utilize como página local.
3. Compartilhe o endereço com os colaboradores da empresa.
